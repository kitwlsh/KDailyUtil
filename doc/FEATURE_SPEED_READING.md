# 📖 빠른 독서 훈련 (Speed Reading) — 기능 설계서 v1.0

> 배움터(LearningHub)의 "지식 플러스(준비 중)" 탭을 **빠른 독서 훈련** 탭으로 대체하는 기능 설계.
> 김병완 「1시간에 1권 퀀텀 독서법」을 읽고 영감을 받았으나, **저작권 안전을 위해 책 내용을 복제하지 않고 일반 속독 훈련 원리로 독자 구현**한다.
> 작성: 2026-06-24

---

## 0. 배경 / 시장 조사

- 속독 앱 카테고리는 이미 큼: 해외 **Spreeder, Spritz, Balto, Speed Reading Coach**, 국내 안드로이드 **"속독"** 앱 등. 대부분 **RSVP(단어 점멸)** + **가이드 페이서** 방식.
- **"퀀텀독서법" 전용 앱은 없음** (김병완 칼리지 오프라인 유료 강좌로만 운영).
- 우리 차별화: 기존 앱에 없는 **AI 이해도 채점(Gemini) + 통계/배지 연동** 으로 "빨리 + 이해" 를 함께 측정.

---

## 1. 저작권 / 상표 가이드 (필독)

> ⚠️ 법률 자문이 아닌 실무 가이드. 핵심: **"방법(아이디어)"은 보호 대상이 아니고 "표현(문장·그림)"이 보호된다.**

**해도 되는 것**
- 일반 속독 기법(RSVP, 포인터/페이서, 청킹, 시야 확장, 안구 운동, 묵독 억제) 구현 — 수십 년 된 공용 기법.
- 안내 문구·설명을 **직접 작성한 원문**으로 제공.
- 연습 지문: ① **저작권 만료 공개 텍스트**(고전·만료 문학) ② **사용자 본인 붙여넣기** ③ **AI(Gemini) 생성 원문**.
- 책을 **영감/추천 도서로 언급**("김병완 「1시간에 1권 퀀텀 독서법」 참고/추천"). 제목·저자 적시는 사실 적시라 문제 없음.

**하면 안 되는 것**
- 책의 문장·15단계 명칭과 설명·삽화/도표를 **그대로 복제**.
- **"퀀텀독서법"을 기능/제품 브랜드명으로 사용** (상표·제휴 오인 우려).
- 저자/프로그램의 인증·제휴를 암시.

**핵심 정리**
- "출처 명시"는 복제의 면죄부가 아님 — 출처를 밝혀도 보호 표현 복제는 침해.
- 배포(공유) 앱은 개인 사용보다 기준이 높음 + 스토어 IP 정책 준수 필요.
- 면책 문구(필수): *"본 기능은 일반 속독 훈련 원리에 기반한 독자 구현이며 특정 도서·저자·프로그램과 무관합니다. 효과는 개인차가 있습니다."*
- 권장 크레딧(선택): *"속독 원리에 관심이 있다면 김병완 「1시간에 1권 퀀텀 독서법」을 추천합니다."*

## 2. 기능 구성

배움터 탭1을 **"빠른 독서 훈련"** 허브로 교체. 허브 = 훈련 모듈 목록 + 오늘의 추천 + 진척.

| # | 모듈 | 동작 | 일반 기법 | 구현 난이도 |
|---|------|------|----------|------|
| ① | **집중 워밍업** | 화면 중앙 한 점 응시 + 호흡 원 확축(30초~2분) | 중심 응시·집중 | 🟢 애니메이션+타이머 |
| ② | **리듬 페이서** | 지문에 하이라이트 바가 줄 단위로 자동 이동, 속도(줄/초·WPM) 조절 | 포인터/페이서법, 묵독 억제 | 🟢 애니메이션 |
| ③ | **단어 점멸 (RSVP)** | 한 단어/구절씩 중앙에 빠르게 점멸, WPM 조절, 최적 응시점 강조 | RSVP/Spritz | 🟢 타이머+Text |
| ④ | **묶어 읽기** | 한 줄을 2~3덩어리로 끊어 표시, 레벨업 시 덩어리 폭 확대 | 청킹·시야 확장 | 🟡 텍스트 분할 |
| ⑤ | **안구 추적** | 점이 좌우/지그재그로 이동, 눈으로 따라가기 | 안구 워밍업 | 🟡 Canvas |

지문 소스: 내장 공개 텍스트 / 사용자 붙여넣기 / AI 생성.

---

## 3. 차별화 — WPM + AI 이해도 (앱 고유)

- **WPM 측정**: 읽기 시작 시각 → 완료 탭 → (글자수/단어수 기준) 분당 단어수 계산. 훈련 전/후 비교.
- **AI 이해도 채점**: 읽은 지문으로 **Gemini가 3문제 자동 생성·채점** (기존 `GeminiManager.generateQuizzesFromText` / `verifySubjectiveAnswer` 재활용). → **WPM × 이해도** 동시 기록으로 "속도만 빠르고 이해 0" 방지.
- **통계/배지**: 기존 `QuizStatsManager`(골드 배지) 연동.

---

## 4. 진척 / 커리큘럼

- **"21일 독서력 챌린지"**(일반 명칭): 일자별 추천 훈련 세트 + 완료 체크 + 연속일(streak).
- 시작 WPM 기준 측정 → 일자별 **WPM·이해도 추이 그래프**(증시 Canvas 스파크라인 재활용).
- 저장: DataStore(진척/베스트 기록) — 기존 `SettingsRepository` 패턴.

---

## 5. 기술 / 아키텍처

- 현 스택만으로 구현 가능(Jetpack Compose, Coroutines, DataStore, Gemini, 기존 차트/통계). **새 의존성 없음.**
- 신규 파일(예상):
  - `ui/screens/ReadingTrainingScreen.kt` — 허브 + 각 훈련 모듈 화면
  - `ui/viewmodel/ReadingTrainingViewModel.kt` — 상태/타이머/WPM/진척
  - 지문 데이터(공개 텍스트 상수 또는 AI 생성)
- `LearningHubScreen.kt`의 탭1 placeholder(라인 94 부근) 교체 + 탭명 변경("빠른 독서 훈련").

## 6. 단계별 로드맵

- **MVP (1차) — ✅ 완료**: 허브 + ①집중 워밍업 ②리듬 페이서(자동 스크롤) ③단어 점멸(RSVP) + WPM + 진척/streak + 면책/크레딧.
- **Phase 2-a — ✅ 완료**: **사용자 텍스트 붙여넣기**(연습 지문 직접 입력) + **AI 이해도 채점**(읽기 후 Gemini가 4지선다 3문제 생성·채점 → WPM×이해도, 최고 이해도 기록).
  - 흐름: 페이서/RSVP 완료 → 결과 화면(이번 WPM) → "이해도 퀴즈 풀기" → AI 문제 풀이·채점 → 최고 이해도 저장.
  - 신규: `GeminiManager.generateComprehensionQuiz()`, `ReadingTrainingViewModel.generateComprehension()`, repo `best_comprehension`.
- **Phase 2-b(일부) — ✅ 완료**: **책 페이지 촬영/이미지 업로드 → Gemini Vision OCR로 본문 추출 → 그 텍스트로 훈련**.
  - 퀴즈 생성기의 카메라/갤러리·이미지 압축 패턴 재활용. 신규: `GeminiManager.extractTextFromImage()`, `ReadingTrainingViewModel.extractTextFromImage()`.
  - 이미지는 전송 전 자동 축소(요청 용량 최소화, OCR은 최대 2048px·퀴즈 스캔은 1280px — `inSampleSize` 디코드 + `createScaledBitmap`). 한 번에 1페이지 권장.
- **Phase 2-c — ✅ 완료**: **지문 보관함**(촬영/붙여넣은 지문을 썸네일과 함께 저장 → 리스트에서 선택/삭제) + **④묶어 읽기(청크)** 드릴(묶음 크기 2~5단어 조절).
  - 신규: `ReadingTrainingRepository`의 `SavedPassage` 저장(`reading_passages.json` + `reading_pages/` 이미지), VM `savedPassages`/`savePassageFromImage`/`savePassageText`/`deletePassage`.
- **Phase 2-d — ✅ 완료**: ⑤**안구 추적** 드릴(움직이는 점 따라가기, 속도 조절) + 집중 워밍업 호흡 신호 개선(시선 분산 방지: 원의 크기+밝기 변화로 들숨/날숨 표현, 라벨은 원 중앙) + OCR 안정화(해상도 2048, 두 쪽 펼침 프롬프트).
- **Phase 2-e — ✅ 완료**: 보관함 **선택 지문 표시**(✓·골드 강조·"사용 중") + **WPM 추이 스파크라인**(최근 30회) + **21일 챌린지**(최근 21일 훈련 점등, N/21).
  - 신규 저장: `reading_wpm_history.json`(WPM 이력), DataStore `trained_dates`(훈련일 집합).
- **이후 후보**: 사용자 텍스트 라이브러리 편집/제목 변경, 난이도 자동 추천, 통계 상세 화면 등.
