# 📱 KDailyUtil

데일리 라이프스타일을 더 스마트하고 고급스럽게 만들어주는 통합 유틸리티 앱입니다.

## ✨ 최근 업데이트: AI 이미지 시각 퀴즈 완성 (2026.06)
KDailyUtil의 핵심 기능인 **KuizGenius AI 퀴즈 플랫폼**에 이미지 기반 시각 퀴즈 출제 기능이 완전히 통합되었습니다.

- **🖼️ 그림/시각 매칭형 퀴즈 (신규)**: Gemini AI가 이미지 속 그림 요소의 Bounding Box 좌표를 감지하고, 해당 영역을 자동으로 크롭하여 문제 이미지로 표시하는 완전한 시각 퀴즈 파이프라인 구현.
- **📐 Bounding Box 정밀 크롭**: AI가 반환한 0~1000 비율 좌표를 실제 픽셀로 변환, 5% 여백 패딩 포함 자동 크롭 후 앱 내부 저장소에 영속 저장.
- **🗂️ 퀴즈 유형별 권한 분리 버그 수정**: 원격 동기화된 퀴즈(클라우드 ☁️)가 사용자 커스텀 퀴즈(별표 ⭐)로 잘못 분류되던 UI 버그 완전 수정.
- **🔊 고품질 효과음 시스템**: 정답/오답/완료 효과음을 프리미엄 MP3로 교체 및 리소스 컴파일 구조 개선.
- **🎯 AI 채점 강화**: 주관식 답안에 대한 Gemini AI 의미론적 채점 + 1단계 로컬 휴리스틱 결합 이중 채점 시스템.

## ✨ 주요 기능

### 📰 뉴스 키워드 브리핑 (Morning Briefing)
- 사용자가 설정한 관심사/키워드별 국내 최신 뉴스 수집 및 카테고리 탭 이동 시 **최상단 자동 스크롤 리셋**.
- **AI 요약**: Gemini 1.5 Flash 엔진을 통해 기사를 자연스러운 대화체로 요약.
- **다중 AI 명령어 및 서브 탭**: 복수의 커스텀 분석 요청 사항을 등록하여 상단 서브 탭 클릭 한 번으로 빠른 브리핑 전환.
- **스마트 캐싱**: 기생성된 분석 결과에 대한 인메모리 캐시 적용 및 분석 시간 명시.
- **TTS 낭독**: 수집된 뉴스 요약을 음성으로 들려주어 바쁜 아침 시간에 시각적 자유 제공.

### 📈 증시 카테고리 및 관심 종목 퀵 브라우징 (Morning Stocks)
- **고정 증시 카테고리**: 삭제 불가능하며 항상 상단에 노출되는 프리미엄 골드 스타일의 **[증시]** 카테고리 제공.
- **관심 종목 설정**: 설정창에서 코스피, 나스닥, 가상화폐, 테슬라, 엔비디아 등 나만의 관심 종목/증시 키워드를 입력 칩(InputChip)으로 추가 가능.
- **상단 서브 탭**: 증시 카테고리 선택 시 관심 종목들이 상단 탭으로 즉시 로드되며, 클릭 시 해당 종목 최신 뉴스 퀵 서칭.

### 2. 오디오 캡처 및 관리 (Audio Capture & Management)
- **고성능 로딩**: 대량의 파일도 지연 없이 불러오는 최적화된 데이터 로딩 시스템.
- **혁신적 UI/UX**:
    - **통합형 플레이어**: 별도의 재생 탭 없이 어디서든 제어 가능한 **지속형 미니 플레이어** 도입.
    - **확장형 컨트롤**: 미니 플레이어를 확장하여 상세 조작이 가능한 **바텀 시트 플레이어**.
    - **탭 간소화**: 녹음, 파일, 목록 중심의 직관적인 3개 탭 구성.
- **스마트 파일 관리**:
    - **중복 자동 제거**: 표준 경로(Canonical Path) 기반의 정확한 파일 중복 체크.
    - **상세 정보 확인**: 파일의 전체 경로, 크기, 생성일을 확인할 수 있는 상세 정보 다이얼로그.
    - **안전한 삭제**: 휴지통 기능을 포함한 안정적인 파일 이동 및 복구 로직.
    - **가져오기/숨기기**: 외부 파일 가져오기 및 보안을 위한 파일 숨김 기능.
- **고급 설정**: 비트레이트, 샘플링 레이트, 녹음 소스(마이크/내부 오디오) 커스텀 설정.
- **지능형 재생 제어**:
    - **블루투스 대응**: 블루투스 이어폰이나 스피커 연결이 해제되면 자동으로 재생을 일시정지(`NoisyAudioReceiver`)하여 의도치 않은 외부 출력을 방지.
    - **반복 재생 로직 최적화**: 재생목록 내 순차 재생, 전체 반복, 셔플 모드 버그 수정 및 안정화.
- **파일 및 저장소 보안 최적화**:
    - **Scoped Storage 완벽 대응**: 안드로이드 11+ 보안 정책에 맞춰 재생목록 데이터는 **내부 저장소**에, 녹음 파일은 **앱 전용 외부 저장소**(`Android/data/.../files`)에 안전하게 보관.
    - **자동 마이그레이션**: 이전 버전의 데이터를 감지하여 새로운 통합 폴더로 안전하게 자동 이동.
    - **외부 목록 임포트**: `.plt` 파일을 직접 선택하여 재생목록으로 즉시 등록 가능 (Toast 피드백 지원).
- **비간섭 플로팅 컨트롤러**:
    - 녹음 준비 상태에서 앱을 사용 중일 때는 UI를 가리지 않으며, **백그라운드로 전환될 때만** 플로팅 아이콘이 나타나도록 라이프사이클 최적화.

### 🚗 뉴스 쉐도잉 (News Shadowing)
- **고급 사설/칼럼 중심**: 학습 가치가 높은 오피니언 리더들의 글을 본문까지 통째로 추출하여 학습.
- **쉐도잉 반복 루프**: TTS 낭독 -> 대기 및 녹음 -> 연습 음성 즉시 재청취 루프 구현.
- **운전 안전 UI**: 고대비 블랙 테마와 대형 버튼으로 조작 편리성 극대화.

### 🧠 AI 퀴즈 및 창작 플랫폼 (KuizGenius)
- **다중 카테고리 및 원격 동기화**: 우리말 겨루기, 트렌드 말하기, 상식 백과, 세계 여행 4대 기본 카테고리와 서버에서 실시간으로 배포되는 최신 퀴즈 자동 동기화.
- **퀴즈 유형별 엄격한 권한 분리**:
  - **공식 및 동기화 퀴즈 (구름 `☁️` 표시)**: 개발자 서버와 동기화된 공식 문제 패키지는 데이터 무결성을 위해 **읽기 전용**으로 설정되어 삭제나 외부 공유가 불가능합니다.
  - **내가 만든 커스텀 퀴즈 (별표 `⭐` 표시)**: AI 사진 스캔, 웹 크롤러, 수동 작성 등으로 직접 만들거나 외부에서 가져온 나만의 퀴즈 패키지이며, **내보내기(공유) 및 삭제(휴지통)** 기능이 완벽히 지원됩니다.
- **창작자 스위트 (KuizGenius Creator Suite)**:
  - **🖼️ 그림/시각 매칭형 퀴즈 (신규)**: 이미지 스캔 탭에서 "그림/시각 매칭형" 선택 시 Gemini AI가 이미지 내 개별 그림 요소의 위치(Bounding Box)를 자동 탐지 → 해당 영역 자동 크롭 → 내부 저장소(`cropped_quizzes/`) 저장 → 퀴즈 풀기 화면에서 크롭 이미지와 함께 문제 출제. Coil 이미지 라이브러리로 로컬 경로 이미지 렌더링.
  - **사진 찍기 및 이미지 분석 스캔 (Photo Scanner)**: 교과서, 문제집 등 이미지를 다중 캡처(카메라/갤러리)하여 AI 엔진이 맥락을 분석하고 개념을 파악하여 **저작권을 우회하는 독창적 문제로 재창작**. 이전 생성 문제 및 오답 통계와 융합한 표적 문제 설계 지원.
  - **웹 크롤러 스캔 (Web Crawler)**: 입력된 웹 기사나 문서를 Jsoup 라이브러리로 정밀 크롤링하여 기사 맥락을 저격하는 퀴즈를 즉각 추출 및 출제.
  - **수동 작성 및 AI 자동완성 (Manual Builder & AI Autofill)**: 질문과 정답만 작성하면 Gemini 2.5 Flash AI가 그럴싸한 **오답 보기 3개와 개념 해설을 단 한 번의 클릭으로 자동 보완**.
- **출제자 프로필 및 법적 주의사항 고지**:
  - 오프라인 고유 장치 식별자(`deviceHashId`) 생성 및 닉네임 설정을 통한 출제자 익명/실명 저작성 보장.
  - 저작권 경고 및 퀴즈 신뢰성 법적 면책 텍스트 노출.
- **성취도 분석 및 배지 시스템 (Achievements & Badges)**:
  - 사용자별 시도 횟수, 정답 횟수 및 퀴즈 정답률을 실시간 집계하여 문제마다 누적 도전 현황 표시.
  - 퀴즈 활동 점수에 따라 "퀴즈 초보자", "스캔 마스터", "크롤링 전문가", "퀴즈 장인" 등의 골드 프리미엄 배지 자동 해금.
- **패키지 내보내기 및 파일 공유 (Share & Backup)**:
  - 내가 만든 커스텀 카테고리를 표준화된 `.kquiz` 파일로 빌드 및 내보내기하여 다른 KDailyUtil 사용자들과 손쉽게 공유 가능. (이미지 퀴즈의 크롭 이미지 경로도 함께 직렬화)
- **스크롤 통합 UX 고도화**:
  - 화면 높이가 제한된 모바일 환경에 대응하여, 출제자 프로필 설정 영역을 각 탭의 스크롤 컨테이너 최상단으로 내장. 화면을 아래로 내리면 자연스럽게 스크롤 아웃(Scroll out)되어 카메라/크롤러 화면이 최대 세로 스페이스를 확보하도록 유연한 레이아웃 설계.

## 🛠 기술 스택

- **UI**: Jetpack Compose (Modern & Responsive UI)
- **Image Loading**: Coil 2.6.0 (`coil-compose`) — 로컬 파일 경로 및 URL 기반 비동기 이미지 렌더링
- **Networking**: Jsoup (RSS Scraping & Web Crawling)
- **AI**: Google Generative AI SDK (Gemini 2.5 Flash) — 텍스트/이미지 분석, Bounding Box 감지, 의미론적 채점
- **Concurrency**: Kotlin Coroutines & Flow
- **Data Persistence**: Preferences DataStore, Internal File Storage (JSON)
- **Audio**: TextToSpeech (TTS), MediaRecorder, MediaPlayer

## 🛠 최근 업데이트 및 작업 현황 (2026-06-10)

### 🖼️ AI 이미지 크롭 기반 시각(그림 매칭) 퀴즈 완성 (2026.06)
- **Bounding Box 기반 자동 크롭 파이프라인**:
  - Gemini AI가 이미지에서 개별 그림 요소의 2D 좌표(`[ymin, xmin, ymax, xmax]`, 0~1000 비율)를 정밀 감지.
  - `cropBitmapFromBoundingBox()`: 비율 좌표 → 픽셀 변환 + 5% 여백 패딩 적용 후 Bitmap 자동 크롭.
  - `saveBitmapToInternalStorage()`: 크롭 이미지를 `filesDir/cropped_quizzes/` 에 PNG로 영속 저장.
  - 카테고리 삭제 시 연결된 크롭 이미지 파일도 함께 자동 삭제 (저장소 누수 방지).
- **Coil 라이브러리 통합**:
  - `coil-compose 2.6.0` 추가 및 `AsyncImage`로 로컬 절대 경로 이미지 비동기 렌더링.
  - 퀴즈 풀기(`QuizPlayScreen`) 문제 카드와 퀴즈 생성 미리보기 다이얼로그 양쪽 모두에서 이미지 표시.
- **퀴즈 카테고리 권한 분리 UI 버그 수정**:
  - 원격 서버에서 동기화된 퀴즈(`맞춤법 및 띄어쓰기`, `고난이도 고유어` 등)가 커스텀 퀴즈로 잘못 분류되어 별표(`⭐`)와 삭제 버튼이 노출되던 크리티컬 버그 수정.
  - `isDefault` 판별 로직을 공식 내장/원격 동기화 카테고리를 모두 포함하도록 확장.
- **AI 주관식 의미론적 채점 시스템 (2단계 채점)**:
  - 1단계: 로컬 휴리스틱(공백/특수문자 무시) 정확 매칭.
  - 2단계: Gemini AI `verifySubjectiveAnswer()` 메서드로 문맥적 동의어 판정 및 부분 정답 처리.
  - 채점 중 로딩 상태 시각화 및 중복 클릭 방지 처리.
- **효과음 리소스 시스템 고도화**:
  - 기존 레트로 풍 `.wav` 파일 → 고품질 `.mp3` 효과음(`quiz_correct`, `quiz_wrong`, `quiz_finish`)으로 교체.
  - 리소스 컴파일러 충돌 방지를 위한 백업 파일 폴더 분리 구조 적용.
